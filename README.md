# 🖼️ Image Editor

A simple and responsive image editor built with **HTML**, **CSS**, and **Vanilla JavaScript**. Users can upload an image, apply various filters, use preset effects, reset changes, and download the edited image.

---

## ✨ Features

- 🎛️ Adjust image filters using sliders
  - Brightness
  - Contrast
  - Saturation
  - Hue Rotate
  - Blur
  - Grayscale
  - Sepia
  - Opacity
  - Invert
- 🎨 One-click preset filters
  - Vintage
  - Old School
  - Drama
  - Noir
  - Warm
  - Cool
  - Retro
  - Dreamy
  - Cyberpunk
  - and more...
- 🔄 Reset all filters
- 💾 Download the edited image
- 📱 Fully responsive design

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Canvas API
